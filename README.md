# Chatbot
Personal Finance Coach is an intelligent, interactive chatbot designed to guide users through various aspects of personal finance. Whether you're planning your budget, exploring investment options, or building an emergency fund, this AI-powered assistant offers practical, easy-to-understand financial advice tailored to your needs.
🔍 Features
✅ Chatbot powered by Gemini Pro (Google Generative AI)

✅ Predefined quick-access topics in the sidebar

✅ Custom user queries supported

✅ Clean and responsive UI using Streamlit

✅ Styled chat interface with user and coach bubbles

✅ Option to reset chat history
